## gotchas

- [CRLF and encoding mismatches fake corruption and drift](gotchas/cross-platform-text-false-positives.md) — A hash mismatch across Windows/Linux is not proof a file drifted \(CRLF\). Normalize line endings before comparing. Garbled log text is often UTF-8 read as CP1252, not corruption.
- [A bracket in a git pathspec is a glob, and returns zero silently](gotchas/git-bracket-pathspec.md) — git reads \[name\] in a pathspec as a character class, so grep/log against a bracket-named folder silently matches nothing, which looks the same as "the code is gone". Use :\(literal\).
- [Mass uniform test failures usually mean one missing prerequisite](gotchas/uniform-failures-single-cause.md) — When a huge block of tests fails uniformly with empty or identical details, suspect one missing prerequisite \(interpreter path, env var, credential\) near the top of the log, not a regression.
- [Backgrounded processes on Windows drop your env vars](gotchas/windows-cross-shell-env-vars.md) — Prefixing env vars on a backgrounded command from Git Bash silently fails to pass them on. Set them inside the process's own shell with a wrapper script.
